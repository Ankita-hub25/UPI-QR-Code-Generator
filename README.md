# UPI QR Code Generator 💳📱

A simple Python project built in Jupyter Notebook that generates custom UPI payment QR codes for **PhonePe**, **Paytm**, and **Google Pay** using a user's UPI ID.

## 🚀 Features
- Takes any valid UPI ID as user input.
- Automatically generates payment links for PhonePe, Paytm, and Google Pay.
- Saves the generated QR codes locally as `.png` image files (`phonepe_qr.png`, `paytm_qr.png`, `google_pay_qr.png`).
- Displays the QR codes directly on the screen.

```

## ▶️ How to Run
1. Clone this repository or download `QR Code Generator.ipynb`.
2. Open the notebook in **Jupyter Notebook** or **VS Code**.
3. Run the cell and enter your **UPI ID** when prompted.
4. Your QR code images will be generated and saved in the project folder.
